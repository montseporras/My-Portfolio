# Montserrat Porras Portfolio

Professional portfolio website built with HTML5, CSS3, and JavaScript.

## Structure

\`\`\`
/assets
  /documents
  /icons
  /images
  /logos
/css
/js
/fonts

index.html
README.md
\`\`\`

## Main sections

- Hero with resume download.
- About section.
- Technology stack grouped by category.
- Portfolio cards with project image, description, actions, and badges.
- Contact section and social links.

## Add a new project

Open \`index.html\`, find the comment inside \`#portfolio\`, duplicate the existing \`.project-card\`, and replace the image, text, links, and badges.
